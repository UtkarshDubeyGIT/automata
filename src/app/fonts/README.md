# Product fonts

These local WOFF2 files are the same Latin variable-font assets used by the Zidane AI (`growthos`) application: Sora for display text, Hanken Grotesk for interface text, and Geist Mono for code and numeric values. They are loaded with `next/font/local`, so builds and page views do not depend on Google Fonts availability.

All three font families are distributed under the SIL Open Font License 1.1. The original family copyright and license notices are included alongside the fonts.
